# Tostaduría Moka & Co.

Proyecto académico de sitio web empresarial para la actividad **1.1 Identificación de una necesidad y propuesta de proyecto web**. Moka & Co. es un negocio ficticio de café de especialidad. Su identidad, historia, productos, precios, promoción y datos de contacto son simulados; las fotografías de Unsplash son referencias genéricas, no imágenes verificadas del negocio.

## Ejecutar

Abre `index.html` en un navegador moderno. La página no requiere instalación ni compilación. Bootstrap 5.3.2, Google Fonts y fotografías se cargan desde CDN, por lo que esos recursos necesitan conexión a internet.

## Estructura

```text
index.html
css/styles.css
js/main.js
img/README.md
docs/
.github/copilot-instructions.md
```

El formulario valida en el navegador y **no transmite ni almacena** los datos. No existe backend, compra ni sistema de reservas.
